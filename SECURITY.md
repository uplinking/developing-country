# Security

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](../../security/advisories/new) rather than in a public issue.

Include what you found, how to reproduce it, and the impact you expect. We will acknowledge the
report and keep you updated until it is fixed.

In scope: the site (`developing-country.org`), the explorer, API, OAuth and MCP server
(`explore.developing-country.org`), and the code in this repository.
